# Remove Spaces from a String in Java

## Description
This program removes all ordinary spaces from a user-provided string using Java's `replace()` method.

## Sample Input
```text
Hello World Java
```

## Sample Output
```text
HelloWorldJava
```

## Concepts Used
- Java Strings
- Scanner class
- `replace()` method
- User input and output

## How to Run
```bash
javac RemoveSpaces.java
java RemoveSpaces
```
